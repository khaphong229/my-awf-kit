---
description: Solo dev workflow to create a feature quickly with lightweight planning and verification
---

1. Restate the feature briefly
   - One paragraph summary
   - Inputs / outputs
   - Constraints (if any)

2. Sketch a lightweight plan
   - Files to touch
   - Key logic steps
   - Edge cases to watch
   - Do NOT overthink

3. Implement the feature
   - Follow existing conventions
   - Reuse existing code
   - Keep diff focused

4. Quick verification
   // turbo
   - Run minimal command (dev server / test / build)
   - If UI exists: visually verify main flow

5. Produce a short summary
   - What was added
   - How to verify
   - Known limitations (if any)
