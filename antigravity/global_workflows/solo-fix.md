---
description: Solo dev workflow to fix a bug with minimal overhead
---

1. Describe the bug
   - Expected vs actual
   - Repro steps
   - Error/log if available

2. Identify the root cause
   - Where the bug likely lives
   - Why it happens

3. Apply the fix
   - Minimal change
   - Avoid refactor unless necessary

4. Verify the fix
   // turbo
   - Re-run repro steps
   - Confirm expected behavior

5. Summarize
   - Root cause
   - Fix applied
