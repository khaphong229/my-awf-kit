   - Why refactor?
   - What must NOT change?

2. List affected files
   - Keep scope small

3. Refactor
   - Improve structure/readability
   - No behavior change

4. Verify core behavior
   // turbo

5. Summarize changes
   - Before vs after
   - Any follow-up ideas
